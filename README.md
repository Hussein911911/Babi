# نظام إدارة الأدوية — مكتب الفيض الدوائي العلمي

نظام متكامل لإدارة عمل المكاتب العلمية الدوائية: المخزون، المبيعات والفواتير، المشتريات، التقارير، وتنبيهات الصلاحية — بواجهة عربية كاملة (RTL).

**إصدار الخادم 2.0** — البيانات محفوظة في قاعدة بيانات مركزية (SQLite) على الخادم، ومشتركة بين جميع الأجهزة والمستخدمين لحظياً.

---

## ✨ المزايا

| القسم | الوصف |
|---|---|
| 🔐 تسجيل الدخول | مستخدمون بصلاحيات (مدير النظام / موظف مبيعات)، كلمات مرور مشفّرة (scrypt)، جلسات 30 يوماً |
| 📊 لوحة التحكم | حالة المخزون، مبيعات آخر 7 أيام، الأصناف الحرجة، آخر الفواتير |
| 💊 المخزون | إضافة/تعديل/حذف الأصناف، بحث وفلاتر، حالة كل صنف (متوفر، منخفض، نافد، قرب الانتهاء، منتهي) |
| 🧾 المبيعات | سلة بيع بالقطعة أو الشريط، خصومات، دمج أسطر، نقدي/آجل، اعتماد بخصم من المخزون، طباعة فاتورة، إدارة الصيدليات والمذاخر |
| 🚚 المشتريات | طلبيات من الشركات، استلام يضيف الكميات ويحدّث سعر الشراء تلقائياً |
| 📈 التقارير | إيراد وربح آخر 30 يوماً، رسوم بيانية، تصدير CSV، نسخة احتياطية JSON (تنزيل واستيراد) |
| 🔔 التنبيهات | إنذار مبكر قبل انتهاء الصلاحية بـ 90 يوماً + حدود الطلب |
| 👥 إدارة المستخدمين | المدير يضيف مستخدمين، يعيّن كلمات مرورهم، ويحذفهم — من صفحة الإعدادات |

## 🧱 البنية التقنية

```
├── server/              خادم Node.js + Express
│   ├── index.js         REST API + تقديم الواجهة المبنية
│   ├── db.js            طبقة قاعدة البيانات (SQLite المدمجة في Node)
│   ├── seed-data.mjs    البيانات التجريبية (تُزرع عند أول تشغيل)
│   └── data/            ملف قاعدة البيانات alfayd.db (يُنشأ تلقائياً)
├── website-files/       واجهة React 19 + Vite 7 + Tailwind 4 (TypeScript)
└── package.json         سكربتات التشغيل على مستوى المشروع
```

- **بدون أي اعتماديات تحتاج ترجمة برمجية** — قاعدة البيانات مدمجة في Node نفسه (`node:sqlite`)، المطلوب فقط **Node 22 أو أحدث**.
- ملف قاعدة البيانات واحد (`server/data/alfayd.db`) — النسخ الاحتياطي = نسخ هذا الملف.

## 🚀 التشغيل المحلي

```bash
# 1) تثبيت الاعتماديات (الخادم + الواجهة)
npm install

# 2) بناء الواجهة
npm run build

# 3) تشغيل النظام (الواجهة والـ API على نفس المنفذ)
npm start
# → http://localhost:3001
```

للتطوير (تعديل مباشر مع إعادة تحميل):

```bash
npm run dev:server   # الخادم على المنفذ 3001
npm run dev:web      # الواجهة على المنفذ 5173 مع تمرير /api للخادم
```

## 🌐 النشر على الإنترنت (مع دومين خاص)

الخادم خدمة Node واحدة تقدّم الواجهة والـ API معاً. أسهل طريقة هي **Render** (تدعم الدومينات الخاصة مجاناً):

### على Render:
1. ارفع المشروع إلى مستودع GitHub.
2. من لوحة Render اختر **New → Web Service** واربط المستودع.
3. الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `node server/index.js`
   - **Environment:** أضف متغير `DATA_DIR` = `/var/data` (مسار دائم لقاعدة البيانات)
4. أضف **Persistent Disk** بمسار `/var/data` (حتى لا تضيع البيانات عند إعادة النشر).
5. اربط الدومين الخاص من **Settings → Custom Domain**.

### بدائل تعمل بنفس الطريقة:
- **Railway:** مشروع Node عادي + Volume لمسار `DATA_DIR`.
- **VPS خاص (Ubuntu):**
  ```bash
  # تثبيت Node 22 ثم:
  git clone <المستودع> && cd <المجلد>
  npm install && npm run build
  DATA_DIR=/var/lib/alfayd PORT=3001 node server/index.js
  # مع Nginx كوكيل عكسي للدومين + شهادة Let's Encrypt
  ```

### متغيرات البيئة
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `3001` |
| `DATA_DIR` | مجلد قاعدة البيانات (اجعله قرصاً دائماً بالاستضافة) | `server/data` |

## 💾 النسخ الاحتياطي

- **من داخل النظام:** صفحة التقارير ← «نسخة احتياطية» (ملف JSON كامل)، و«استيراد نسخة احتياطية» لاسترجاعها.
- **على مستوى الخادم:** انسخ ملف `server/data/alfayd.db` دورياً.

## 🗑️ إدارة البيانات

- **استعادة البيانات التجريبية:** من الإعدادات/التقارير — يعيد الأصناف والفواتير الافتراضية (يستبدل البيانات الحالية للجميع).
- **حذف جميع البيانات:** من الإعدادات — يمسح كل شيء من الخادم (المستخدمون يبقون).

## 🔒 الأمان

- كلمات المرور مشفّرة بخوارزمية **scrypt** مع ملح عشوائي — لا تُخزن نصاً صريحاً أبداً.
- الجلسات رموز عشوائية 256-بت تنتهي بعد 30 يوماً أو عند تسجيل الخروج.
- عمليات إدارة المستخدمين وحذف البيانات محصورة بمدير النظام.
- يُنصح بتشغيل النظام خلف HTTPS (تلقائي على Render وخدمات الاستضافة).
